# Локальное хранилище

Core создаёт `users.json` и `portfolios.json`. После успешного обновления
Parser Service создаёт `rates.json` и `exchange_rates.json`.
Локальные JSON-файлы исключены из Git.

`rates.json` содержит `pairs` с последними курсами и `last_refresh`.
`exchange_rates.json` содержит список измерений; идентификатор — пара и
время получения ответа в UTC. Повторная запись того же ID не дублируется.
В `meta` сохраняются время обновления источника и данные HTTP-запроса.

TTL задаётся в `rates_ttl_seconds` (по умолчанию 300 секунд).
Устаревший курс требует `update-rates`; Core не обращается к API.

Путь к хранилищу задаётся перед командой через `--data-dir PATH` или
переменной окружения `VALUTATRADE_DATA_DIR`. По умолчанию это `data/`
относительно текущей рабочей папки.
Имена JSON-файлов задаются в `[tool.valutatrade]`.

Файлы сохраняются атомарной заменой. Core может читать снимок, пока Parser
обновляет его. Для одного каталога данных запускайте один пишущий Parser.
Аварийное завершение между записью истории и снимка может оставить кэш
позади истории; следующий запуск обновления сохраняет историю измерений.
