# Локальное хранилище

При запуске приложение создаёт `users.json`, `portfolios.json` и `rates.json`.
Эти файлы исключены из Git: они содержат локальные учётные данные, балансы
и обновляемый кэш курсов. Исходно списки пользователей и портфелей пусты.

Все даты записываются в ISO 8601 с часовым поясом UTC. Старые даты без
часового пояса читаются как UTC. Курсы `DemoStub` фиксированы и предназначены
для симуляции. Свежесть кэша задаётся в `rates_ttl_seconds` секции
`[tool.valutatrade]` (по умолчанию 300 секунд). Затем курс обновляется
через заглушку. Неизвестные и устаревшие недоступные курсы не подменяются.

Путь к хранилищу задаётся перед командой через `--data-dir PATH` или
переменной окружения `VALUTATRADE_DATA_DIR`. По умолчанию это `data/`
относительно текущей рабочей папки.
Имена JSON-файлов задаются в `[tool.valutatrade]`.

Данные рассчитаны на один запущенный процесс. Каждый файл сохраняется
атомарной заменой; регистрация откатывает портфель при обычном сбое записи
пользователя. Транзакция между файлами при аварийном завершении процесса
и одновременная запись несколькими экземплярами пока не поддерживаются.
